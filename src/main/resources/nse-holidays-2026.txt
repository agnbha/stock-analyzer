# NSE trading holidays for 2026 (equities, the "CM" segment), one ISO date per line.
# Weekends are skipped automatically and need not be listed; the few that fall on
# one are kept so the file reads like NSE's own list.
#
# Source: NSE's holiday master, fetched 2026-10-28 and checked against the sessions
# already stored (none of the weekday holidays before that date has any data):
#   https://www.nseindia.com/resources/exchange-communication-holidays
#   https://www.nseindia.com/api/holiday-master?type=trading   (JSON; the "CM" list)
#
# NSE publishes next year's list in December. Until it is added the daemon treats
# those days as trading days and fires session alerts on them. A run that returns
# no data for any symbol also records the date as a non-trading day, so history
# self-corrects afterwards - but scheduled alerts look forward and cannot.
#
# DefaultTradingCalendar warns at startup when the last date here is less than
# 30 days away (from 25 November, for this file), which is the cue to add next
# year's list: copy it from the page above, or take the "CM" entries of the API,
# into a nse-holidays-2027.txt and point alerts.holidays.file at it.
